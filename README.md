### **NFS-Inspired Car Configurator with AR Viewing**

---

### **Project Overview**  
The **NFS-Inspired Car Configurator with AR Viewing** is a dynamic Unity-based application that allows users to **customize cars** with over **65 material options** and view them in **Augmented Reality (AR)**. Developed in just **3 days** as part of a company assignment, the project integrates advanced design patterns, Unity's **New Input System**, and the **Universal Render Pipeline (URP)** to deliver a seamless and optimized experience.  

---

### **Key Features**  
- 🚗 **Car Customization**:  
   - Over **65 material options** for car personalization.  
   - Enhanced user engagement with extensive customization options.  

- 📱 **AR Car Viewing**:  
   - Sophisticated AR car spawning mechanism.  
   - Accurate placement using **Vector3.Dot** and plane normals to calculate Y-position.  

- 🛠 **Advanced Architecture**:  
   - **Observer Pattern**: Events and delegates for modular and decoupled communication.  
   - Clean, **scalable codebase** with Unity’s component-based architecture.  

- 🎮 **New Input System**:  
   - Replaced the traditional Input Manager for **reliable input handling**.  
   - Avoided string references for better efficiency.  

- 🎨 **Optimized Rendering**:  
   - Integrated **URP** for improved graphical fidelity and mobile performance.  
   - Optimized 3D models and applied custom textures using **Substance Painter 3D**.  

- ⚡ **Quick Development**:  
   - Completed the project **from scratch within 3 days**.  

---

### **Tech Stack**  
- **Engine**: Unity  
- **Rendering**: Universal Render Pipeline (URP)  
- **AR Framework**: AR Foundation  
- **3D Tools**: Sketchfab, Substance Painter 3D  
- **Design Patterns**: Observer Pattern

### **How to Run the Project**  
1. **Requirements**:  
   - Unity 2021.3 or higher  
   - AR Foundation package installed  
   - Universal Render Pipeline (URP) setup  

2. **Steps**:  
   - Clone the repository:  
     ```bash
     git clone https://github.com/DhroovSama/AR-Car-Configurator.git
     cd AR-Car-Configurator
     ```  
   - Open the project in Unity.  
   - Build and run on an **AR-compatible mobile device**.
